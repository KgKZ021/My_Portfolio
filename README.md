## 📁 Modular Folder Structure

```
My_Profolio/
├── index.html                      # Semantic DOM hierarchy & accessible markup
├── README.md                       # Project documentation
├── plans/
│   └── portfolio_overhaul_plan.md # Architectural blueprint
├── css/
│   ├── style.scss                  # Main SCSS entry importing all partials
│   ├── style.css                   # Compiled CSS
│   └── partials/                   # Modular SCSS components
│       ├── _variables.scss         # Color palette, typography variables
│       ├── _base.scss              # Global resets, scrollbars, canvas, scanlines
│       ├── _typography.scss        # Orbitron, Rajdhani, Chakra Petch fonts
│       ├── _components.scss        # HUD frames, buttons, glow badges
│       ├── _navbar.scss            # Cyber navigation bar
│       ├── _hero.scss              # Hero banner & typewriter effect
│       ├── _about.scss             # Player profile & attributes HUD
│       ├── _skills.scss            # Categorized skills & certifications grid
│       ├── _experience.scss        # Career timeline
│       ├── _projects.scss          # Video/Image showcase cards
│       ├── _education.scss         # University timeline & coursework
│       └── _footer.scss            # Terminal footer
├── js/
│   ├── script.js                   # Main ES module initializer
│   └── modules/
│       ├── particles.js            # Interactive particle canvas network
│       ├── typewriter.js           # Dynamic HUD typewriter effect
│       ├── hud-effects.js          # Micro-interactions & back-to-top
│       └── observer.js             # Intersection Observer scroll reveals
└── Resources/                      # Media assets (videos, screenshots)
```

## ⚙️ Setup & Usage

1. Open the repository in your code editor.
2. Compile `css/style.scss` to `css/style.css` using your preferred Sass compiler (or Live Sass Compiler).
3. Open `index.html` in any modern web browser or serve via a local static server (e.g., Live Server).
